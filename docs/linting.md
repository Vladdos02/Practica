## Обраний інструмент
Для проєкту було обрано **Checkstyle** — популярний інструмент для мови Java, що дозволяє автоматизувати перевірку дотримання стандартів оформлення коду та виявляти потенційні помилки на ранніх етапах.

## Обґрунтування вибору
* **Інтеграція**: Checkstyle легко інтегрується в Maven через плагін `maven-checkstyle-plugin`.
* **Стандартизація**: Допомагає підтримувати єдиний стиль написання коду (відступи, іменування, структура імпортів).
* **Профілактика помилок**: Правила на кшталт `NeedBraces` допомагають уникати логічних помилок при редагуванні блоків `if/else`.

## Опис налаштованих правил (checkstyle.xml)
* **AvoidStarImport**: Забороняє використання імпортів через `*`, що робить залежності класу прозорими.
* **UnusedImports**: Виявляє зайвий код, що не використовується.
* **Indentation**: Встановлює стандарт відступів у 4 пробіли.
* **NeedBraces**: Вимагає обов'язкового використання фігурних дужок для всіх керуючих конструкцій.
