## Stock Management System

Система для управління складом на базі Spring Boot.

## Функціонал
- Управління товарами (додавання, видалення, редагування).
- Категоризація товарів та відстеження локацій на складі.
- Система резервування товарів.
- Вбудований веб-інтерфейс.

## Технології
- Java 17+, Spring Boot 3.x
- Spring Data JPA (H2 Database)
- Frontend: HTML5, CSS3, JavaScript (Fetch API)

## Як запустити
1. Склонуйте репозиторій.
2. Виконайте `./mvnw spring-boot:run`.
3. Відкрийте `http://localhost:8080/frontend/index.html` у браузері.
